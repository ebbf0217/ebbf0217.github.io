실전 기록

지금 틀린 상태인 문제

5초 규칙 · 해석하기 전에
  1. 보기 4개를 먼저 본다. 모양이 비슷하면(-tion, -ive, -ively) 품사 문제, 다 다른 단어면 어휘·접속사 문제.
  2. 품사 문제는 빈칸 바로 앞뒤 두 단어만 보고 고른다.
  3. 빈칸 뒤가 주어 + 동사면 접속사, 명사(구)면 전치사.
  4. 문장 안에 that → so / such, than → 비교급, nor → neither, or → either / whether.
  5. 해석은 그래도 안 풀릴 때만. 한 문제에 30초가 넘으면 찍고 넘어간다.
